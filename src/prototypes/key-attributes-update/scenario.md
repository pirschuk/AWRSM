# Обновление ключевых атрибутов

Задача сотрудника: массово обновить значения атрибутов предметов залога через файл.

## Сценарий
1. Пользователь открывает задачу №48271 (статус «Назначена»), вкладка «Обновление атрибутов».
2. Скачивает файл с актуальными данными (формирует система), правит локально.
3. Загружает файл в ту же форму → проверка содержимого и формата.
4. Проверка ок → «Обновить данные» → прогресс.
5. Итог: таблица по типам предметов залога (всего / обновлено / не обновлено). Задача → «Завершена», данные на вкладке «Предметы залога» обновлены. Часть предметов может остаться необновлённой — это норма.

## Статусы
Назначена → В работе (первое действие: скачивание или загрузка) → Завершена. Из любого нефинального — Отменена. Завершена и Отменена — только просмотр.

## Действия в шапке
- **Переназначить** — модалка с выбором сотрудника → переход на главную + уведомление справа сверху.
- **Отменить** — подтверждение → статус «Отменена», форма заблокирована.

## Ветки для демонстрации (по имени загружаемого файла)
- имя содержит `error` → ошибка проверки файла (таблица ошибок + отчёт);
- имя содержит `fail` → ошибка при обновлении (отчёт + повтор);
- любое другое → успех.
