# AWRSM

Проектируем веб-интерфейсы на базе Ant Design (antd 6, React, TypeScript, Vite).

## Правила

1. **Только компоненты Ant Design.** Не используем сторонние UI-библиотеки и не пишем с нуля то, что есть в antd.
2. **Токены** берём из antd (`theme.token`, `ConfigProvider`). Никаких захардкоженных цветов, отступов, радиусов — только токены.
3. **Кастомные компоненты** допустимы только на основе готовых antd-компонентов и только после явного обсуждения с пользователем. Каждый такой компонент записываем в `docs/custom-components.md` (название, на чём основан, что изменено, почему).
4. **Паттерны** используем стандартные из antd (https://ant.design/docs/spec/introduce). Если отступаем от них под себя — проговариваем и записываем в `docs/patterns.md` (паттерн, что изменили, почему). Следующие интерфейсы делаем уже с учётом этих записей.
5. Перед созданием интерфейса читаем `docs/custom-components.md` и `docs/patterns.md`.
6. Не уверены, есть ли нужный компонент в antd, — сначала смотрим документацию, потом спрашиваем.

## Команды

- `npm run dev` — dev-сервер
- `npm run build` — сборка
