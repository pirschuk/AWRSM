description: Опубликовать прототипы на GitHub Pages
---
Публикация: $ARGUMENTS

1. `npm run build` — должен пройти без ошибок.
2. Коммит и push в `main` (в конце сообщения коммита — атрибуция из системных указаний).
3. GitHub Actions (`.github/workflows/pages.yml`) собирает и выкладывает автоматически.
4. Сообщаю ссылку: https://pirschuk.github.io/AWRSM/ и ссылки на конкретные прототипы (`/#/<slug>`).
5. Если Pages не включён — говорю пользователю, что включить: Settings → Pages → Source: GitHub Actions.
