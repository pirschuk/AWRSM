description: Создать новый прототип (папка, сценарий, регистрация, роут)
---
Создаю новый прототип: $ARGUMENTS

1. Папка `src/prototypes/<slug>/` (slug — латиницей, kebab-case).
2. `scenario.md` — сценарий: роль пользователя, цель, шаги, ветки, состояния. Шаги сценария = кликабельный путь в прототипе.
3. `index.tsx` — экспорт компонента-прототипа. Навигация между экранами внутри — через роуты react-router (HashRouter).
4. Регистрация в `src/prototypes/registry.ts` (slug, название, описание, статус: draft/review/ready, связанные прототипы).
5. Данные — реалистичные моки в `data.ts` рядом (длинные названия, много строк, пустые поля, русские ФИО, суммы в рублях).
6. Состояния: загрузка, пусто, ошибка, нет прав — где применимо.
Проверка: `npm run build`.
